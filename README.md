# Tether

A Mac app for Claude Code. Each chat runs your own `claude` CLI, so your login, CLAUDE.md, skills, MCP servers and permission mode all apply, and sessions stay compatible with the terminal and VS Code. Tether adds what the terminal can't: voice input, circling things on screen, clickable file paths, a Shelf for pages Claude makes, approvals docked above the message box, and long chats that keep going with notes instead of compaction.

See [the highlights](https://htmlpreview.github.io/?https://github.com/jfroy525/tether/blob/main/docs/highlights.html) for the main features, or the [one-page tour](https://htmlpreview.github.io/?https://github.com/jfroy525/tether/blob/main/docs/features.html) for everything it does.

## Install

You need:
- A Mac with macOS 12 or newer (Apple silicon or Intel)
- [Claude Code](https://claude.com/claude-code), installed and logged in (run `claude` once in Terminal)
- Python 3.11 or newer, or [uv](https://docs.astral.sh/uv/)
- Optional: [GitHub CLI](https://cli.github.com) (`gh`) for pull requests in the Changes tab, VS Code for ⌥-click to open files

Then:

```sh
git clone https://github.com/jfroy525/tether.git
cd tether
zsh build_app.sh
open ~/Applications/Tether.app
```

The build makes `~/Applications/Tether.app`, which runs the code in this folder. If you move the folder, run `zsh build_app.sh` again.

The same icon glows when a newer Claude Code is out (checked against npm at most hourly); **Update Claude Code** runs `claude update`, which works for Homebrew, npm and the native installer. Open chats keep the old version until they restart. Settings › Updates shows this copy's version and the last check, or why it can't check (for example "Couldn't reach GitHub: …"), with **Check now**.

**Report a problem:** red error lines in a chat have a **Report** link, and Settings › Advanced has **Report a problem**. Tether fills in a GitHub issue with its version, macOS, Claude Code's version, the chat's model, the error and the end of `~/Library/Logs/Tether.log`, with your user name replaced. You see and edit all of it first; it opens on GitHub, where you click Create. Issues are public, and chat text, files and pictures are never included.

**Updates:** when a newer Tether is on GitHub, a glowing download icon appears next to the settings gear. Hover it for what's in the update; click it to see what changed (the new entries in [CHANGELOG.md](CHANGELOG.md)), then **Update and restart**. Settings › Updates › **Change log** shows every update. If Claude is working in any chat, Tether waits until it's done, and the chats you had open come back after the restart. If you installed before the update icon existed, update once by hand: `cd ~/tether && git pull`, then quit Tether (⌘Q) and reopen it.

The first time you use each of these, macOS asks for permission (System Settings › Privacy & Security):
- **Microphone:** dictation. Speech is turned into text on your Mac with Whisper; the speech model (about 150 MB) downloads the first time.
- **Screen Recording:** circling things on screen, Claude looking at your screen, and glass that adjusts to what's behind it.
- **Notifications:** when a chat finishes or needs you while Tether is in the background. They show Tether's logo, and clicking one opens that chat. Keep Tether.app in your Applications folder (the build puts it in `~/Applications`), or macOS refuses them. Turn them off in Settings.
- **Waiting on you panel:** while Tether is in the Dock, hidden or behind another app, what needs you (questions, approvals, handoffs, failed jobs) floats over the app you're in. Answer, Run or Deny, Send a handoff, or type a reply without bringing Tether forward; after you send, the keyboard goes back to your app. Settings › Notifications sets where it shows (a corner, bottom center, next to the Dock on whichever side it sits, or wherever you drag it), whether it starts folded, what it shows, and Hide details for screen sharing.

## Cost and privacy

Tether uses your Claude Code login and plan; it has no account or server of its own. Chats cost what they cost in Claude Code. Notes and recall lookups use Haiku through the same login, about a cent per notes update and a tenth of a cent per lookup; Settings › Sessions turns notes off. Settings, notes and search indexes stay on your Mac in `~/Library/Application Support/Tether/`.

## Files

- `workbench.py`: the window, hotkeys, screen overlays and bridge to the page
- `engine.py`: one `claude -p` stream-json process per session (permissions, diffs, events)
- `history.py`: past sessions from ~/.claude/projects · `repos.py`: git, gh and (if you use it) Databricks status and repo discovery
- `voice.py`: dictation · `screen.py`, `markup.html`: screenshots, marks and reading text on screen · `lift.py`: tables lifted onto the Shelf
- `recall.py`: the per-session search index and the Haiku lookup · `notes.py`: running notes · `slim.py`: removes old screenshots from transcripts
- `notifier.py`: Mac notifications · `panel.py` + `ui/panel.html`: the floating Waiting on you panel · `dock.py`: the Dock icon's pulse while Claude works · `boot/`: starts Tether when Tether.app runs Python as its own program, so macOS shows notifications as Tether's
- `cc_update.py`: compares the installed Claude Code with the newest on npm and runs `claude update`
- `updater.py`: checks GitHub for a newer Tether (at most every hour), moves this folder to GitHub's version (setting aside any local edits in git) and restarts
- `wb_mcp.py`: tools for Claude (look_at_screen, list_windows, mark_up_screen, show_table, show_artifact, recall, session_notes)
- `artifacts.py`: the Shelf's versions and which chat showed each (in the support folder, never the project), sealed pages, changed lines · `artifact_snap.py`: draws a page off screen for Claude to look at
- `ui/`: the page (`app.js`, `markdown.js`, `runner.js` and `critters.js` for the working-line animations, `app.css` for the Float glass layout) · `make_icon.py`: the Tether icon

Logs: ~/Library/Logs/Tether.log. Settings: ~/Library/Application Support/Tether/.
