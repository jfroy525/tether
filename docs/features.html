Claude Code, without the terminal.

Tether is a calm Mac window around Claude Code. You talk, point and click. Claude does the work, and everything it touches is one click away.

Install: paste this in Terminal
git clone https://github.com/jfroy525/tether.git ~/tether && cd ~/tether && zsh build_app.sh && open ~/Applications/Tether.app
Needs Claude Code, logged in, and Python 3.11 or newer
