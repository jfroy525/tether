Tether

A Mac app for Claude Code. It runs your own Claude Code with your login and settings, costs less on long chats, and shows what Claude makes beside the chat.

git clone https://github.com/jfroy525/tether.git ~/tether && cd ~/tether && zsh build_app.sh && open ~/Applications/Tether.app

Paste it in Terminal. Needs macOS 12 or newer, Claude Code installed and logged in, and Python 3.11 or newer. After that Tether updates itself.

Lower cost on long chats

Picking a long chat back up costs about 82% less, and about 58% less over 17 days of long chats. Tether keeps running notes and starts a fresh session with them, where Claude Code would compact the chat into a summary.

  • Notes keep decisions, exact facts and open itemsHeader › Notes
  • A fresh session carries the notes and the latest conversation word for wordautomatic
  • Recall lets Claude search the whole historyClaude's tool
  • Ask a side question without adding to the chat⌘/

Same Claude

Each chat runs your own Claude Code, so your CLAUDE.md, skills, tools and permission mode all apply.

Works with the terminal

Sessions stay compatible with the terminal and VS Code, so you can move between them.

Cost and privacy

What it costs

Chats cost what they cost in Claude Code. Notes add about a cent per update and recall about a tenth of a cent per lookup. Notes can be turned off.

What stays on your Mac

Settings, notes and search indexes. Speech is turned into text on your Mac, and text read from the screen is read on your Mac.

What macOS asks for

Microphone for talking, Screen Recording for circling and reading the screen, and Notifications. Each is asked the first time you use it.
