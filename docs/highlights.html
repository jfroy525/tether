Tether

A Mac app for Claude Code. You get the same Claude, with what it makes shown beside the chat, long chats that don't forget, and your screen one click away.

Install
git clone https://github.com/jfroy525/tether.git ~/tether && cd ~/tether && zsh build_app.sh && open ~/Applications/Tether.app
Paste it in Terminal. You need macOS 12 or newer, Claude Code installed and logged in, and Python 3.11 or newer. After that, Tether updates itself from the glowing icon.

Notes and fresh starts, instead of compaction

When a chat gets long, Claude Code usually squeezes it into a summary and details get lost. Tether keeps running notes instead: decisions, exact facts, open items. When it's time, it starts a fresh session with those notes and the latest conversation word for word. Claude can still search the whole history with recall.

The Shelf

Make it yours

Tether is made of frosted glass, so your desktop shows softly through it, and it adjusts its text to stay readable over whatever is behind it. Pick any accent color, and choose how replies land and what runs along while Claude works. Try the controls.

Click it, don't copy it

Every file path in a reply is a link. Click the file name to preview it beside the chat, with the lines Claude read lit up. Click a folder to open it in Finder.

Talk instead of type

Hold a key anywhere on your Mac and talk. Let go and the words land in the message box. It's transcribed on your Mac, so nothing is sent anywhere.
